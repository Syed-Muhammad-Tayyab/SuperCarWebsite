# 📜 Code of Conduct

We want this project to be welcoming to everyone.

**Expected:** be respectful, give constructive feedback, accept feedback gracefully, and focus on what is best for the project.

**Not acceptable:** harassment, insults, discriminatory language, personal attacks, or publishing others' private information.

Maintainers may remove comments, commits or contributions that break these rules, and may block repeat offenders. Report problems by opening an issue or contacting the maintainer via the GitHub profile.
